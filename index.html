HOW IT WORKS

From raw NASA data to a useful signal

01Fetch

TerraPulse requests open-event metadata from NASA EONET.

02Normalize

Events are grouped, mapped, searched and sorted consistently.

03Prioritize

A transparent local heuristic highlights signals worth checking first.

04Remember

People can save events locally for a personal watchlist.

IMPORTANT

Priority is a prototype signal, not an official warning.

The score is calculated by TerraPulse from event category and available metadata. It does not predict danger and should never replace official emergency services, government alerts, or scientific analysis.
